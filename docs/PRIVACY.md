# Little Legends — V1 Privacy / Parent Trust Contract

Little Legends V1 is designed as a local, child-safe tablet game.

- No advertising appears in child mode.
- No child-mode external links.
- No chat, public profile, social feed or user-generated publishing.
- No behavioural advertising.
- Camera and microphone access are not required.
- Profiles, learning progress, rewards and settings are stored locally on the device.
- V1 asks only for a first name or nickname, age band 2–5 and simple local preferences.
- No account is required for the current build.
- Purchases are not enabled in the current build. Any future purchase surface must be behind the Parent Gate.
- Parents can export or reset local data from the Parent Area.

This document describes the implemented V1 product behaviour. Store/legal wording should be reviewed before public release.
