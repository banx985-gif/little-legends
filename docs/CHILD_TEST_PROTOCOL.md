# Little Legends — Milestone 26 Child Test Protocol

Test separately with ages 2, 3, 4 and 5. Do not coach the child through core activities.

Observe and record: first tap, mis-taps/incorrect attempts, lost drags, confusing instructions, activity completion, hint frequency, replay requests, boredom points, favourite characters, favourite rewards and parent intervention frequency.

Use Parent Area → TEST to start a local observation session for the child's age. The game automatically records first-tap timing, attempts, lost drags, hints, activity starts/completions and Parent Area interventions. The parent can mark boredom, help, confusing instructions, replay requests and favourite character/reward moments.

Gate 4 is not passed by automation. It passes only when most core activities are independently understandable without adult instruction across the intended age range.
