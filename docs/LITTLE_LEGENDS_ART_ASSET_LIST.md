# LITTLE LEGENDS: MAGIC WORLD
## Art & Asset Production List

**Platform:** JavaScript + HTML5 Canvas  
**Target:** Tablet  
**Art direction:** Bright dimensional candy-style 2D/2.5D assets with strong silhouettes, large expressions and simple readable detail.

---

# 1. ASSET PRODUCTION RULE

Do not produce the full asset library immediately.

Art should be created in this order:

1. Prototype interaction assets.
2. Pip.
3. Rory's Dino Picnic.
4. Wonder Island starter.
5. Reusable UI and effects.
6. Rainbow Village.
7. Dino Valley.
8. Animal Forest.
9. Literacy/music/life-skill additions.
10. Launch-scale rewards and cosmetics.

Every asset should have a clear gameplay purpose.

---

# 2. TECHNICAL ART FORMAT

Recommended source:

- High-resolution layered PSD/Krita/Affinity files or equivalent.
- Export final sprites as PNG or WebP with transparency.
- Use sprite sheets for animations.
- Keep original master files separate from exported runtime assets.

Recommended runtime categories:

```text
/assets/characters
/assets/creatures
/assets/worlds
/assets/objects
/assets/activities
/assets/rewards
/assets/ui
/assets/fx
/assets/audio
```

---

# 3. VISUAL STYLE

Characters:

- Large head
- Large readable eyes
- Soft rounded shapes
- Clear emotional silhouettes
- Minimal tiny detail
- High readability at tablet scale
- Strong pose changes
- Squash-and-stretch friendly

Objects:

- Toy-like
- Chunky
- Clearly separable
- Very obvious interaction affordance
- Minimal background clutter

Worlds:

- Colourful
- Layered depth
- Low visual noise
- Large landmarks
- Wide clear interaction zones

# 44. SPRITE SHEET RULES

Character sprite sheets should be organised by animation.

Example:

```text
pip_idle.webp
pip_happy.webp
pip_point.webp
pip_celebrate.webp
```

Or consolidated atlas if tooling supports it reliably.

Metadata should contain:

- Frame width
- Frame height
- Frame count
- FPS
- Loop
- Anchor point

# 46. COSMETIC LAYERING

Pip should be designed with consistent layers:

```text
body
face
eyes
headwear
facewear
bodywear
back accessory
front accessory
```

This avoids redrawing Pip for every outfit.

---

# 47. SCALE GUIDELINES

Create art at higher than final render resolution.

At runtime:

- Do not scale tiny low-resolution sprites upward.
- Ensure all tappable objects remain sharp on high-DPI tablets.
- Keep interactive silhouettes readable at a glance.

# 52. ART MILESTONE CHECKLIST

## Art Gate A — Prototype readability

A two-year-old immediately notices the interactable object.

## Art Gate B — Character attachment

Children recognise Pip and react positively.

## Art Gate C — Touch clarity

Interactive objects are visually distinct from decoration.

## Art Gate D — Reward desire

Children show interest in newly unlocked creatures/items.

## Art Gate E — World coherence

Assets from different activity types still feel like the same game.

## Art Gate F — Performance

Art runs smoothly on target tablets without excessive memory use.
